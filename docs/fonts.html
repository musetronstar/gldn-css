Three font pairings

Each pairing sets sans, serif and mono on the same golden scale. Headings use the sans by default; each card also shows a serif heading.

Choice: pending user review. No pairing is selected by default.

Light theme

A. System fonts

The default: fonts that ship with each operating system, so nothing downloads. The serif is Palatino where the system has it.

Sans for interface and prose

A memex keeps trails of associations, and every tag has its place in one tree. Its ID reads as inline mammal code too.
