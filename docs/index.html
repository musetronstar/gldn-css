The divine proportional semantic CSS system

Every proportion on this page derives from one constant: the golden ratio phi. Resize the window and watch the splits hold their ratio.

see the golden splits

golden splits

The fixed split deducts each column's golden share of the row gutter from its basis, so the columns plus the gutter fill the container in exact proportion; the fluid split grows the columns by weights phi and 1 instead. Both hold the ratio at any width. The measured ratios below are computed live from the rendered boxes.

the golden division cascade

type and space on the golden scale

Type advances by half steps of phi and space by whole steps. Both use one fluid base, computed in CSS with calc() and pow().

one fluid base

The base is 16px at a 320px viewport and 18px at 1200px. It grows smoothly between 20rem and 75rem, with no responsive jump.

buttons beside fields

A field, a bare button and every button variant share one height and boundary, so controls set side by side align. gldn-btn marks the primary action; gldn-btn-secondary, gldn-btn-quiet and gldn-btn-danger change only its colors.

layout primitives

The grid, switcher, cluster and frames answer to their own width, not the viewport's. The narrow column and the wide column hold the same markup: the grid fits fewer tracks, the switcher stacks, the cluster wraps, and the frames keep their golden ratio. A sided composition keeps its side beside the text until the text would take less than 61.8%. Golden rows use the same intrinsic rule at 48rem and above; their default token also stacks them on phone-width viewports. Density classes step the space scale, gutter included, one power of phi.

sided

The side keeps its own width beside the text while the text keeps at least 61.8% of the composition. Narrow the window and, when the text would fall below that share, the side moves above it and both take the full width.

numerals and capitals

Old-style figures sit in running text like lowercase letters: 1618 and 2026. Lining figures of one width align in columns: 1618 and 2026. Small capitals set an acronym such as CSS at the height of the text, and a short label can be set in capitals, spaced apart.
